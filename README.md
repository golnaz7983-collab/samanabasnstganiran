# سامانه بازنشستگان ایران

نسخه فعلی یک وب‌اپ فارسی و واکنش‌گرا برای گروه‌های بازنشستگان است و به همان پروژه Supabase سامانه سینما متصل شده است.

## امکانات
- ثبت‌نام با نام کاربری و انتخاب شهر، **بدون ایمیل و بدون ورود ایمیلی**
- نمایش گروه‌های فقط همان شهر
- ساخت گروه جدید و ذخیره روی سرور مشترک
- چت واقعی داخل هر گروه با همگام‌سازی لحظه‌ای
- انتشار پست و عکس برای همه کاربران
- نظرسنجی و رأی‌دهی مشترک
- صدور سند قابل چاپ / ذخیره PDF برای گروه
- پروفایل و تغییر شهر
- طراحی مناسب موبایل و دسکتاپ
- لوگوی سامانه به‌صورت داخلی در صفحه قرار گرفته است

## داده‌های آنلاین
داده‌های اصلی سامانه در Supabase ذخیره می‌شوند؛ بنابراین گروه‌ها، پیام‌ها، پست‌ها و نظرسنجی‌ها بین کاربران و دستگاه‌های مختلف مشترک هستند. برای هویت کاربر فقط یک شناسه محلی مرورگر و نام کاربری/شهر استفاده می‌شود و **ایمیل یا رمز عبور در این سامانه استفاده نمی‌شود**.
