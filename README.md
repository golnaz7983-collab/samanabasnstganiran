# سامانه بازنشستگان ایران

نسخه فعلی یک وب‌اپ فارسی و واکنش‌گرا برای گروه‌های بازنشستگان است.

## امکانات
- ثبت‌نام اولیه با نام کاربری و انتخاب شهر، بدون ایمیل
- نمایش گروه‌های فقط همان شهر
- اطلاعات پارک، آدرس، ساعت فعالیت و آلاچیق
- ساخت گروه جدید برای شهر انتخاب‌شده
- گفت‌وگوی متنی داخل هر گروه
- انتشار پست و عکس
- نظرسنجی و رأی‌دهی
- صدور سند قابل چاپ / ذخیره PDF برای گروه
- پروفایل و تغییر شهر
- طراحی مناسب موبایل و دسکتاپ
- لوگوی سامانه به‌صورت داخلی در صفحه قرار گرفته است

## انتشار
فایل اصلی پروژه `index.html` است و برای GitHub Pages آماده شده است.

## نکته مهم درباره داده‌ها
در این نسخه، برای اینکه پروژه بدون تنظیمات جانبی فوراً اجرا شود، حساب و محتوای ایجادشده در `localStorage` مرورگر نگهداری می‌شود. بنابراین پیام‌ها و پست‌ها در همان مرورگر کار می‌کنند و هنوز بین دستگاه‌های مختلف کاربران همگام نمی‌شوند.

برای نسخه عمومی و واقعی سامانه، مرحله بعدی اتصال همین رابط به یک پایگاه‌داده آنلاین (مثلاً Supabase) برای احراز هویت، گروه‌ها، پیام‌ها، عکس‌ها و نظرسنجی‌هاست.
